## Known residual gaps (honestly not closed this round)

- **Ablation and Portfolio Monte Carlo have no JSON export / UI-rendered numbers** — only a textual "CLI-only" status row in the Capability Inspector. This satisfies "discoverable, not invisible" but not "fully surfaced with real numbers." Given both are exploratory/diagnostic tools rather than primary scientific findings, this is a defensible triage choice for this round, not a claim that it's finished — listed here rather than silently left off the matrix.
- **The prospective ledger's hash chain has 0 chained events and 4 legacy events** — this is correct and expected (no scoring event has happened yet; draw `#01562` hasn't occurred), not a bug, but it also means the new chain-tamper-detection code has not yet been exercised against a real chained (non-legacy) production event, only against unit-test fixtures and one live no-op CLI run. It will get its first real exercise the next time `research:prospective-freeze`/`append-result` actually writes new lines.
